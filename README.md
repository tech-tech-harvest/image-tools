# 画像ツール

ブラウザだけで動く画像ツール集です。サーバは不要で、`index.html` をブラウザで開くだけで使えます。
画像はすべてブラウザの中で処理され、外部に送信されません。

## できること

| ページ | 内容 |
|---|---|
| 形式変換（`index.html`） | PNG / JPEG / WebP / PDF に変換。GIF・BMP・AVIF なども読み込め、PDF のページを画像に、複数の画像を1つの PDF にもできる（HEIC はブラウザが対応している場合のみ。主に Safari） |
| 画像編集（`edit/`） | 明るさやフィルタの調整、文字・手書きの書き込み、回転・反転・傾き補正、トリミング |
| トリミング＆リサイズ（`resize/`） | 出力サイズ（px・比率）を決めて、切り取る範囲を調整 |
| 画像の結合（`combine/`） | 複数の画像を横・縦・グリッドに並べて1枚に |
| モザイク（`mosaic/`） | 図形やブラシで範囲を指定してモザイク・ぼかし |
| 背景削除（`bg-remove/`） | AI による自動削除、または背景の色を指定して削除。ブラシで手直しもできる |
| 透かし（`watermark/`） | 文字やロゴの透かしを複数の画像にまとめて入れる |
| 位置情報の削除（`metadata/`） | 写真に埋め込まれた撮影場所などの情報を、画質を変えずに削除 |

形式変換・透かし・位置情報の削除では、複数のファイルを ZIP にまとめて保存できます。

## 使い方

1. このフォルダをダウンロード（または `git clone`）する
2. `index.html` をブラウザで開く
3. 上のメニューから使いたい道具を選び、画像をドラッグ＆ドロップする

ビルドやインストールは不要です。

## 動作環境

- Chrome / Edge の最新版を推奨します
- Safari でも大半の機能は使えますが、背景削除の AI は動きません（手動での削除は使えます）。WebP での保存もできない場合があります

## インターネット接続について

背景削除の AI を使うときだけ、初回に AI の部品（[Transformers.js](https://github.com/huggingface/transformers.js) と背景削除モデル [ormbg](https://huggingface.co/onnx-community/ormbg-ONNX)）をインターネットから読み込みます。
このときも画像は送信されず、処理はブラウザの中で行われます。それ以外の機能はオフラインで動きます。

## フォルダ構成

```
index.html, app.js   形式変換
edit/                画像編集
resize/              トリミング＆リサイズ
combine/             画像の結合
mosaic/              モザイク
bg-remove/           背景削除
watermark/           透かし
metadata/            位置情報の削除
nav.js               共通ヘッダ（メニュー）
segmented.js         選択肢のボタン化・説明の吹き出し
style.css            共通のスタイル
vendor/              同梱しているライブラリ
```

各ページは `index.html` と `app.js` の組で、フレームワークは使っていません。
